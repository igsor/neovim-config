# NeoVIM cheat sheet

## ctrlpvim/ctrlp.vim

CTRL-p			Open CTRL-P command line
	F5			Refresh
	CTRL-f		cycle between most recently used files, files, buffers
	CTRL-d		toggle between path and filename-only search
	CTRL-r		toggle between regex and normal search
	CTRL-y		create a new file and its parent directories
